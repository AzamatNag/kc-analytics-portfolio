# A/B-тест нового алгоритма рекомендаций

**Задача:** оценить, увеличивает ли новый алгоритм рекомендаций постов CTR ленты новостей, и решить, раскатывать ли его на всех пользователей.

**Данные:** ClickHouse, таблица `feed_actions` (симулятор социального приложения). АА-тест: 21–27 августа 2026, A/B-тест: 28 августа – 3 сентября 2026.

## Файлы

- `aa_test.ipynb` — проверка системы сплитования: 10 000 симуляций t-теста на подвыборках по 500 пользователей.
- `ab_test.ipynb` — анализ эксперимента: сравнение CTR шестью методами, линеаризованные лайки, выводы и рекомендация.

## Результаты

- **АА-тест:** доля ложноположительных срабатываний 4.55% при пороге 5% — сплитование работает корректно.
- **A/B-тест:** общий CTR в тестовой группе ниже на 0.9 п.п. (0.2003 против 0.2096), различие статистически значимо (бутстреп, бакеты, линеаризация).
- Распределение CTR в тестовой группе стало двугорбым, поэтому обычный t-тест различий не увидел (p = 0.685), а тест Манна-Уитни и линеаризованные лайки увидели.

## Рекомендация

Не раскатывать алгоритм на всех пользователей. Следующий шаг — найти сегмент, в котором CTR вырос, и провести тест на нём.

**Стек:** Python (pandas, scipy, seaborn), ClickHouse, pandahouse.
