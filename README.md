# Продуктовая аналитика социального приложения

Портфолио проектов по продуктовой аналитике: SQL-запросы к ClickHouse, дашборды в Apache Superset, A/B-тесты на Python и выводы для продуктовой команды. Данные — симулятор социального приложения с лентой новостей и мессенджером (курс «Симулятор аналитика», karpov.courses).

## Проекты

| # | Проект | Что внутри |
|---|---|---|
| 01 | [Взаимодействие ленты и мессенджера](01-feed-messages-dashboard/) | Сегментация пользователей по использованию двух сервисов, DAU по сегментам, разрезы по источнику, ОС и стране, сравнение активности в ленте |
| 02 | [Расследование: рекламная кампания и сбой ленты](02-campaign-and-outage-investigation/) | Когортный retention пользователей кампании, поиск причины падения DAU — сбой ленты в четырёх городах при работающем мессенджере |
| 03 | [Активная аудитория по неделям](03-weekly-active-audience/) | Разложение недельной аудитории на new / retained / returned / gone на массивах ClickHouse |
| 04 | [A/B-тест нового алгоритма рекомендаций](04-ab-test-recommendation-algorithm/) | АА-тест системы сплитования, сравнение CTR шестью методами (t-тест, Манн-Уитни, сглаженный CTR, Пуассоновский бутстреп, бакеты, линеаризованные лайки), рекомендация по раскатке |

## Ключевые находки

- **Сервисы почти не пересекаются:** лентой и сообщениями в один день пользуются лишь ~1–2% дневной аудитории.
- **Рекламная кампания не удержала пользователей:** 2 592 новых пользователя, но retention на 1-й день 4,0% против 28,1% у обычного рекламного трафика при одинаковом составе аудитории.
- **Сбой ленты локализован по городам:** в Москве, Санкт-Петербурге, Екатеринбурге и Новосибирске аудитория ленты упала до нуля на весь день, а мессенджер продолжал работать.
- **Органический трафик:** платные пользователи удерживаются хуже органических (8,0% против 12,4% на 20-й день для одной когорты), а с сентября органический приток почти остановился.
- **Новый алгоритм рекомендаций снизил CTR:** общий CTR в тестовой группе 0,2003 против 0,2096 в контроле, распределение стало двугорбым — обычный t-тест различий не увидел (p = 0,685), а бутстреп, бакеты и линеаризация показали значимое падение. Рекомендация — не раскатывать.

## Навыки

- **SQL / ClickHouse:** когортный анализ, условная агрегация (`countIf`, `uniqExactIf`), массивы (`groupUniqArray`, `arrayJoin`, `has`), `UNION ALL` вместо `FULL JOIN` с учётом особенностей ClickHouse
- **BI:** Apache Superset — виртуальные датасеты, time-series и категориальные графики, Big Number с WoW-сравнением, native filters
- **Статистика / Python:** АА- и A/B-тесты, t-тест, тест Манна-Уитни, Пуассоновский бутстреп, бакетное преобразование, линеаризация метрик-отношений (pandas, scipy, seaborn)
- **Анализ:** формулирование гипотез, проверка через независимые разрезы, перекрёстные подтверждения, рекомендации
